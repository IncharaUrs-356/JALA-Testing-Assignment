# JALA Training Assignment — Testing Starter Submission

## Contents
- `JALA_Testing_Assignment.xlsx`: test scenarios, test cases, defect log templates, traceability matrix, test plan and test strategy.
- `selenium_starter.py`: Selenium starter tests. Locators are placeholders and must be checked against the live application.

## Important
This workbook is based on the provided *Web App Requirement Document* for the JALA Student Skills Web Application. The email also references the Magnus training application; confirm with the coordinator whether this is the exact specification intended for the Magnus URL.

## Before submission
1. Execute each test case and fill in actual results and statuses.
2. Report only defects that you reproduce. The five defect rows are templates, not confirmed bugs.
3. Update Selenium locators after inspecting the real page. Do not claim tests passed until they have been run.
4. Never upload passwords, tokens, or screenshots containing personal information.
5. Ask the Technical Coordinator for JIRA access as instructed, then log five verified defects.
6. Upload the completed files to a public GitHub repository only if permitted by the assignment rules.
